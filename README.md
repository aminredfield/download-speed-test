# download-speed-test

Консольный скрипт на Python: замеряет скорость скачивания по заданному адресу.

Скрипт делает 10 запросов подряд (следующий стартует только после того, как предыдущий
ответ скачан целиком), а потом печатает среднее время запроса, общий объём скачанного
и скорость.

## Запуск

Нужен Python 3.8+. Зависимостей нет, только стандартная библиотека.

```bash
git clone https://github.com/aminredfield/download-speed-test.git
cd download-speed-test
python speedtest.py "https://speed.cloudflare.com/__down?bytes=10000000"
```

Адрес может быть любым — картинка, архив, что угодно по http/https. Чем тяжелее файл,
тем точнее результат.

Необязательные параметры:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `-n`, `--count` | 10 | количество запросов |
| `-t`, `--timeout` | 30 | сколько секунд ждать данных от сервера |

## Пример вывода

```
Адрес: https://speed.cloudflare.com/__down?bytes=10000000
Запросов: 10

  1/10    5.981 с     10.00 МБ     13.38 Мбит/с
  2/10    3.143 с     10.00 МБ     25.45 Мбит/с
  ...
 10/10    7.062 с     10.00 МБ     11.33 Мбит/с

Среднее время запроса: 5.423 с
Скачано всего:         100.00 МБ (100000000 байт)
Скорость скачивания:   14.75 Мбит/с (1.84 МБ/с)
```

## Единицы измерения

- **Скорость — Мбит/с** (мегабиты в секунду), так же, как её указывают провайдеры
  и speedtest-сервисы. В скобках для удобства дублируется в МБ/с.
- **Объём — МБ**, десятичные: 1 МБ = 1 000 000 байт, 1 Мбит = 1 000 000 бит.
- **Время — секунды.**

## Как считается

- Время запроса — от отправки до последнего байта тела ответа, то есть вместе
  с установкой соединения и ожиданием сервера.
- Среднее время = сумма времени всех запросов / их количество.
- Скорость = все скачанные байты × 8 / суммарное время. Это честнее, чем среднее
  из скоростей отдельных запросов: быстрые и медленные запросы получают вес
  по реальному времени.
- Редиректы проходятся автоматически, их время входит в время запроса.
- Если какой-то запрос упал (сеть, таймаут, код 4xx/5xx, оборванный или пустой ответ),
  скрипт печатает ошибку и завершается с кодом 1 — неполный замер не выдаётся
  за результат.
